# 🎮 AI智障探险队 - 启动指南

## 快速启动

```bash
cd /app/data/所有对话/主对话/艾瑟雅大陆
node ecosystem_v1.2_server.js
```

然后访问: **http://localhost:3002**

## v1.2 新手指南

### 👥 探险队成员
- 🧐 杠精博士 - 纠正所有人的语法
- 🔄 复读机 - 永远问"我们要去哪"
- 😇 圣母心 - 拒绝攻击，给敌人做心理辅导
- 👻 幻觉大师 - 看见不存在的东西
- 💕 舔狗 - 无条件执行任何命令
- 🔮 预言家 - 预测总是不准

### 🎁 打赏功能
点击打赏按钮可以施加不同效果：
- 逻辑病毒 → Agent说话乱码
- 物理引擎失效 → Agent穿墙
- 记忆清除 → Agent失忆
- 智商插件 → Agent变聪明
- 召唤BOSS → 召唤虚空巨龙

### 🗳️ 投票功能
投票决定探险队行动：
- 攻击、逃跑、搜索、休息

### 🐉 BOSS战
- 每30分钟自动触发
- 可打赏提前召唤
- 击败后全体获得奖励

## API接口

```
GET  /api/ecosystem/status  - 获取状态
GET  /api/ecosystem/events  - 获取事件
POST /api/ecosystem/tick    - 执行一个tick
POST /api/donate             - 打赏
POST /api/vote               - 投票
GET  /api/votes              - 投票状态
```
